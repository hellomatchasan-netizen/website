Where to put real photos
=========================
Drop files with these exact names and they'll appear on the site automatically
(the page falls back to a placeholder box if a file is missing).

home/
  hero.jpg          - portrait photo for the homepage hero (ideal ratio 4:5)

drinks/
  drink-1.jpg       - Matcha San
  drink-2.jpg       - Coconut Cloud San
  drink-3.jpg       - Double Matcha San
  drink-4.jpg       - Strawberry Matcha San
  drink-5.jpg       - Shio San
  (square photos, ratio 1:1)

events/
  event-teaser.jpg  - photo for the "book an event" section on the homepage (ratio 3:2)

about/
  founder.jpg       - founder / whisking photo on the About page (ratio 4:5)

Any common web image format works (.jpg, .png, .webp) - just keep the base
filename the same, e.g. "drink-1.png" instead of "drink-1.jpg", and update the
matching data-src path in index.html if you change the extension.
